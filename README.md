# 📊 Censo Escolar 2025 - Rede Pública — Dashboard Power BI

## 📌 Sobre o projeto

Projeto de Business Intelligence desenvolvido em Power BI para análise dos dados do Censo Escolar 2025, com foco na rede pública de ensino brasileira.

O dashboard consolida indicadores educacionais e permite uma análise interativa da distribuição de matrículas, escolas e registros de docentes em diferentes regiões do país.

## 📈 Principais indicadores

- 36,28 milhões de matrículas
- 136,71 mil escolas
- 2,71 milhões de registros de docentes
- Análises por região, UF e município
- Distribuição por etapa de ensino
- Localização urbana e rural
- Esfera administrativa: municipal, estadual e federal

## 🔎 Principais análises

O dashboard permite analisar:

- Matrículas por etapa de ensino
- Distribuição das matrículas por região
- Ranking de estados e municípios
- Distribuição entre áreas urbanas e rurais
- Matrículas por esfera administrativa
- Filtros interativos por região, UF, município, localização, esfera e etapa de ensino

## 🎯 Objetivo

Transformar dados públicos do Censo Escolar em informações visuais e estratégicas, facilitando a identificação de padrões, concentrações regionais e características da rede pública de ensino brasileira.

## 🛠️ Tecnologias utilizadas

- Power BI
- Power Query
- DAX
- Excel
- Análise e tratamento de dados
